# NEON DASH KIT

ערכה לבניית משחק פלטפורמה ריתמי בדפדפן בסגנון Geometry Dash, באמצעות סוכן קוד.

```
neon-dash-kit/
├── PROMPT.md          ← הפרומפט המלא לסוכן הקוד (זה העיקר)
├── README.md          ← המסמך הזה: מחקר על המשחק + הוראות שימוש
└── assets/            ← ספרייטים, שלב הדגמה, פלטה, preview.html
```

## איך משתמשים

1. פתח `assets/preview.html` בדפדפן כדי לראות את כל הנכסים.
2. פתח שיחה חדשה עם סוכן הקוד (Claude Code / Cursor / Higgsfield) בתיקייה הזו.
3. הדבק את תוכן `PROMPT.md` מהשורה `בנה משחק...` והלאה.
4. התוצאה: `index.html` יחיד לצד `assets/`.
5. הרצה: פתיחה ישירה של הקובץ עובדת; לפיתוח עדיף `python -m http.server 8000`.

## מחקר: מה באמת מרכיב את Geometry Dash

### הליבה
משחק פלטפורמה ריתמי עם auto-scroll וכפתור אחד. השחקן נע במהירות אופקית קבועה, הקלט היחיד הוא לחיצה/החזקה, וכל מגע במכשול = מוות מיידי וחזרה להתחלה. השלב מסונכרן למוזיקה — המכשולים יושבים על הביט, ולכן השחקן לומד את השלב כרצף ריתמי ולא כתגובה ויזואלית.

### קבועי פיזיקה (הבסיס לתחושה הנכונה)
- יחידת רשת: בלוק אחד. מהירות רגילה ≈ **10.39 בלוקים לשנייה**; מכפילי מהירות ≈ 0.807 / 1.0 / 1.243 / 1.502 / 1.849.
- קפיצת קובייה: **גובה 2 בלוקים בכל מהירות**; אורך הקפיצה משתנה לפי המהירות (≈3.5 איטי, ≈4.5 רגיל, ≈5.0 מהיר, ≈5.5 מהיר מאוד).
- מצב Mini מקטין את הדמות ומשנה את הפיזיקה (קפיצה נמוכה יותר, hitbox קטן).
- ה-hitbox של הקוצים קטן משמעותית מהגרפיקה שלהם — זה מה שמונע תחושת עוול.

### מצבי משחק
Cube (קפיצה), Ship (החזקה = תאוצה למעלה), Ball (לחיצה = היפוך כבידה), UFO (לחיצה = דחף באוויר), Wave (תנועה אלכסונית ללא אינרציה), Robot (קפיצה משתנה לפי משך החזקה), Spider (טלפורט בין משטחים), Swing (נוסף ב-2.2), ומצב Platformer עם תנועה חופשית.

### אובייקטים
- **פדים** — מופעלים אוטומטית במגע: צהוב (קפיצה רגילה), ורוד (נמוכה), אדום (גבוהה), כחול (היפוך כבידה).
- **אורבים** — מופעלים רק אם לוחצים בזמן מגע: צהוב, ורוד, אדום, כחול (היפוך כבידה ללא שינוי מיקום), ירוק (קפיצה + היפוך), dash orbs (זינוק בקו ישר).
- **פורטלים** — מצב משחק, כבידה, גודל (mini/big), מהירות, dual (שתי דמויות במקביל), mirror (היפוך כיוון), teleport.
- **מכשולים** — קוצים בגדלים שונים, מסורים מסתובבים, בלוקים מוצקים (מוות בפגיעה בדופן), משופעים, בלוקים מתפוררים/דוהים.
- **איסוף** — 3 מטבעות סודיים בכל שלב.

### מה גורם לזה להרגיש טוב
מוות מיידי + ניסיון חוזר תוך פחות מחצי שנייה, מונה ניסיונות גלוי, פס התקדמות באחוזים עם שיא אישי, מצב אימון עם נקודות ביקורת, ורקע שפועם למוזיקה. בלי אלה זה נשאר עוד משחק קפיצות.

### גרסאות
עדכון 2.2 (דצמבר 2023) הוסיף את מצב ה-Swing, שליטת מצלמה, מצב Platformer ו-SFX editor. הערכה הזו לא מיישמת את כל 2.2 — היא מכוונת לליבה הקלאסית שנותנת 90% מהתחושה.

### הערת זכויות יוצרים
מכניקת משחק אינה מוגנת, אבל השם, הלוגו, הדמויות, השלבים והמוזיקה של Geometry Dash הם של RobTop Games. הנכסים בערכה הזו מקוריים ואינם מכילים שום חומר מהמשחק המקורי. השם המוצע: NEON DASH.
